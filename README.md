# Hot Wheels Garage (Bootstrap 5)

## Run locally
1. Extract the ZIP.
2. Open the `hotwheels-store` folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html`.

## Features
- Responsive Bootstrap 5 layout
- Home, shop, about, contact, sign-in, sign-up, cart pages
- Product search and category filters
- Cart stored in browser localStorage
- Demo contact/auth forms (no backend or real accounts)
- Demo checkout (no payments)

Product names, prices, and emoji are sample data. This is a student project concept, not an official Hot Wheels store.
